# 함께지음 개인정보처리방침

[함께지음](https://github.com/Juno-yea/CareLink) 앱의 개인정보처리방침을 게시하는 저장소입니다.

게시 주소: https://juno-yea.github.io/hamkkejieum-privacy/

## 고칠 때

이 저장소의 `index.html` 은 앱 저장소의 `privacy/index.html` 사본입니다.
**앱 쪽을 먼저 고치고 여기로 복사합니다.** 반대로 하면 앱 저장소의 원본이 뒤처집니다.

앱 저장소에는 함께 고쳐야 할 문서가 둘 더 있습니다.

- `docs/privacy_policy_ko.md`
- `docs/data_safety_answers.md`

세 곳이 어긋나면 게시된 방침이 실제와 달라집니다. 절차는 앱 저장소의
`.claude/skills/privacy-review/SKILL.md`.
